### 🟡 Importantes

#### R-01 — A convenção de views não enxerga a pasta `Shared` de outro módulo

- **Eixo:** 3. Aderência ao spec
- **Referência cruzada:** ADR-001; T-24, T-25
- **Evidência:** `src/FloraBambini.Web/Compartilhado/Mvc/LocalizadorDeViewsPorModulo.cs:33-41`
- **Descrição:** o localizador devolve só as pastas do módulo do controller que atende a requisição, mais `/Compartilhado/Views`.

  ```csharp
  yield return $"/{modulo}/{pasta}/Views/{{1}}/{{0}}.cshtml";
  yield return $"/{modulo}/{pasta}/Views/Shared/{{0}}.cshtml";
  // ...
  yield return "/Compartilhado/Views/{0}.cshtml";
  ```

  A T-25 planeja o menu em `Catalogo/Loja/Views/Shared/Components/MenuDeCategorias/Default.cshtml`, chamado a partir de `_LayoutLoja`. A view de um view component é procurada com o contexto da requisição corrente. Quando a página for atendida por um controller fora do módulo `Catalogo`, o MVC não acha a view do menu e a requisição falha. Dentro do próprio PRD-001 isso atinge a página não encontrada (UI-04), se o controller dela ficar em `Compartilhado`; depois, toda página de outro módulo (carrinho, conta).
- **Por quê é Importante:** não quebra nada hoje, porque só existe um módulo e nenhum view component. Mas a convenção é a entrega central da T-01 e as tarefas seguintes vão escrever sobre ela; descobrir isso na T-25 custa mais que decidir agora.
- **Sugestão de correção:** escolher uma das duas e registrar no plano. (a) O localizador passa a incluir a pasta `Shared` de todos os módulos, depois das do módulo corrente. (b) Fica como está, e a T-25 move a view do menu para `Compartilhado/Views/Components/MenuDeCategorias/`. A opção (b) não exige código agora, só ajuste no caminho da T-25.

#### R-02 — Tarefa `Concluído` sem commit

- **Referência cruzada:** T-01; seção 11 do plano

- **Descrição:** o campo `Status:` da tarefa está `Concluído`, mas o código só existe na árvore de trabalho. Não há mensagem de commit citando `T-01` nem hash no histórico.
- **Por quê é Importante:** o `/leanwork-next` trata tarefa concluída sem hash como inconsistência, e o plano prevê um commit por tarefa para permitir reverter uma regra sem desfazer as demais (seção 8).
- **Sugestão de correção:** commitar a T-01 antes de iniciar a T-02, com a mensagem citando `T-01`, e preencher o hash no Histórico de execução.
